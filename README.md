# 산지도시 부산의 야간 열섬 진단

부산 전역 100m 격자 64,915셀의 위성·지형·건물 데이터로, 평지 도시 기준의 열섬 모델이 산지 도시에서는 설명력이 떨어진다는 것을 실증한 공간 분석 프로젝트.
**지형 변수 추가 시 산지의 설명력 증가분(ΔR² +0.107)이 평지의 2.6배** · 열섬핵 5개 원인 유형 분류 · 행정동 206개 대응 우선순위 도출.

## 핵심 포인트
- 통합: 원자료 3.5GB를 H3 해상도 10(약 100m) 격자 64,915셀로 통합
- 열섬핵: 야간 LST 편차의 LISA + FDR 보정 → 유의한 High-High 격자만 열섬핵으로 확정
- 위계적 회귀: 건물·피복 7변수 → +지형 4변수, ΔR²로 지형의 순효과 측정
- 강건성: 공간 블록 교차검증, 고도 통제 후에도 설명력 유지 확인

## 결과
| 집단 | 건물·피복 R² | 지형 추가 R² | ΔR² |
|---|---|---|---|
| 전체 부산 | 0.334 | 0.408 | +0.074 |
| 산지 (경사 ≥10°) | 0.230 | 0.337 | **+0.107** |
| 평지 (경사 <10°) | 0.401 | 0.442 | +0.041 |

- 지형 효과는 급경사가 아니라 **구릉지(5~20°)에서 가장 큼** — 산복도로가 이 대역에 속함
- 열섬핵 14,264셀을 5개 원인 유형(건물밀집형·지형형·녹지결핍형·복합형·기타)으로 분류
- 행정동 206개 중 46개를 열섬·고령인구 모두 중앙값 이상인 우선 대응 지역으로 선정

## 품질 관리 — 숫자를 손으로 옮기지 않는다

보고서와 시각화에 들어가는 모든 수치를 산출물에서 자동 생성하고, 원자료로 독립 재계산해 대조했습니다.
하나라도 다르면 빌드가 멈춥니다. 이 검증이 실제로 잡아낸 오류는 3건입니다.

- **야간 관측 시각 9시간 오류**: KST가 UTC로 해석되어 야간 LST가 9시간 이른 기온과 매칭되던 문제 (에러·경고 없음)
- **GWR 특이 판정 과소 집계**: 12.2% → 16.5%로 정정해 한계 절에 반영
- **표 렌더링 붕괴**: 구분선·강조 배경 어긋남 수정

## 분석 흐름 및 파일 구성

| 단계 | 파일 | 내용 |
| --- | --- | --- |
| 1. 위성 LST | `part1_LST_final.ipynb` | ECOSTRESS·Landsat 수집, 품질 필터, 격자 집계 |
| 2. 지형 변수 | `part2_pipeline_merged.ipynb` | DEM → 경사·TPI·남서향·지형 SVF |
| 3. 신뢰도 검증 | `part3_pipeline_merged.ipynb` | AWS 지상 관측과 위성 LST 매칭 검증 (148쌍) |
| 4. 건물·사회 변수 | `part4_pipeline_merged.ipynb` | 건폐율·용적밀도·바람길·NDVI·사회지표 |
| 5. 통합 분석 | `part5_analysis.ipynb` | LISA 열섬핵 → 위계적 회귀 → 공간 교차검증 → 유형화 → 우선순위 |

결과만 보려면 `part5_analysis.ipynb` 하나만 열어도 됩니다.

> 원자료가 필요해 노트북을 그대로 재실행할 수는 없습니다. 분석 결과는 각 노트북에 남긴 출력(표·그래프)에서 확인할 수 있습니다.
